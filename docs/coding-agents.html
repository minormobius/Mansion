The Investor — Follow the Money

The Fastest-Growing SaaS Category in History

Coding agents have become the hottest category in venture capital. In less than two years, Cursor went from a $400M valuation to $29.3B—a 73x increase. Sacra estimates Cursor hit $500M ARR in May 2025, making it the fastest-growing SaaS company of all time from $1M to $500M, with revenue doubling approximately every two months.

The Anthropic Mega-Round

Anthropic is raising $10B at a $350B valuation—nearly doubling from $183B just three months ago. The Claude maker's revenue trajectory is extraordinary: Sacra estimates $7B ARR in October 2025, up from $1B at end of 2024, projecting $20-26B for 2026.

The investor stack tells the strategic story: Amazon ($8B total) gets AWS as "primary cloud and training partner"; Google ($3B) supplies Trainium chips; the November 2025 Microsoft-Nvidia deal committed $15B for Anthropic to buy $30B of Azure compute on Nvidia chips.

Revenue Multiples That Make No Sense (Until They Do)

Cursor at $29.3B on $1B ARR is a 29x revenue multiple. For comparison, Salesforce trades at ~7x. But investors aren't buying current revenue—they're buying a theory: that coding itself is being automated, that the TAM is every software engineer's salary, and that network effects from AI training data create winner-take-all dynamics.

Crunchbase notes that Cursor's enterprise revenue grew 100x in 2025 YTD. When Fortune 500 companies—OpenAI, Spotify, Uber, Instacart, Major League Baseball—adopt a tool, the pricing power expands dramatically.

The Developer — Life in the New Stack

What It Actually Feels Like

An October 2025 JetBrains survey found that 85% of 25,000 developers regularly use AI tools. Google's study put adoption at 90%. According to Sonar's developer survey, 72% use AI tools daily, and these tools contribute to approximately 42% of all committed code.

The experience has evolved from "autocomplete on steroids" to something qualitatively different. The major tools:

Cursor

Cursor

The agentic IDE that owns the market

Founded by MIT students in 2022, Cursor forked VS Code and added deep AI integration. Its Agent Mode performs multi-file operations using persistent workspace context. The October 2025 acquisition of Graphite extended capabilities into code review and PR management.

Pricing: $20/month Pro, $40/month Business. Enterprise custom.

Claude Code

Claude Code

Anthropic's terminal-native agent

Released February 2025, Claude Code lives in your terminal rather than an IDE. The Claude Agent SDK (formerly Claude Code SDK) powers both coding and non-coding applications. The October 2025 web launch at claude.ai/code added async capabilities. Version 2.1 introduced subagents and Native LSP support.

Pricing: Included with Claude Pro ($20/mo), Max ($100/mo), or API.

OpenAI Codex

OpenAI Codex

Cloud agents working in parallel

Launched May 2025, Codex runs in sandboxed cloud environments with GitHub integration. GPT-5.2-Codex achieved state-of-the-art on SWE-Bench Pro and Terminal-Bench 2.0. The open-source Codex CLI brought agentic coding to local environments.

Pricing: Included with ChatGPT Plus ($20/mo) and up. Usage-based scaling.

The Workflow Debate

Substack analysis suggests top developers use both: "Cursor for active coding—writing features, fixing simple bugs, rapid prototyping. Claude Code for background heavy lifting—refactoring, test generation, documentation, complex debugging."

The practical difference: Cursor lives in your IDE. Claude Code lives in your terminal. Different contexts, different strengths.

"Vibe Coding"

In February 2025, Andrej Karpathy coined "vibe coding"—describing software in natural language and letting AI handle implementation. The term captured something real: development is shifting from typing code to directing agents.

But studies show zero professional developers actually "vibe"—they control. Every developer in one study maintained strict oversight. As one said: "AI agents are amazing as long as you are the driver & reviewing its work."

"Programming is becoming less about typing out every line and more about guiding, supervising, and collaborating with these agentic tools." — Addy Osmani
The Skeptic — The Case Against the Hype

The Uncomfortable Questions

The numbers are real. The valuations are real. But so are the problems nobody wants to discuss.

The Employment Problem

A Stanford study found that employment among software developers aged 22-25 fell nearly 20% between 2022 and 2025, coinciding with the rise of AI coding tools.

This isn't proof of causation—the 2022-2023 tech layoffs also happened. But the correlation is uncomfortable. If AI tools make senior developers 2-3x more productive, the demand for junior developers mechanically declines. The "AI augments, doesn't replace" narrative may be true for experienced developers while being false for entry-level ones.

The Security Problem

Dark Reading warns: as coders adopt AI agents, security pitfalls lurk. AI-generated code often contains subtle vulnerabilities that pass human review. The 42% of code now AI-generated is 42% of code that no human fully understands.

When the agent suggests a solution, developers often accept it without fully tracing the implications. The speed benefit becomes a security liability.

The Quality Problem

It's unclear how viable "vibe coding" will be long-term. MIT Technology Review notes issues around code quality and maintainability leave plenty of room for skepticism.

AI excels at generating code that works now. It's less reliable at generating code that's maintainable, extensible, and readable. Technical debt accumulates faster when humans don't fully own what they ship.

The Benchmark Problem

Every coding AI company touts benchmark scores—SWE-Bench, HumanEval, Terminal-Bench. But benchmarks measure what benchmarks measure. Real-world codebases involve legacy systems, unclear requirements, organizational politics, and edge cases no benchmark captures.

The jump from "77.2% on SWE-bench Verified" to "can replace human engineers" requires assumptions that don't hold in practice. Deep dive: The Benchmark Problem →

The Valuation Problem

Cursor at 29x revenue assumes revenue will grow into the multiple. But what if:

  • Models commoditize and Cursor loses its edge?
  • Microsoft ships equivalent features in VS Code for free?
  • The next model generation changes the tooling paradigm entirely?
  • Enterprise adoption slows as security concerns grow?

The AI coding market is real. The specific winners are not predetermined. The 2000 dot-com boom taught us that "the internet will change everything" can be true while most internet companies still fail.

The Dependency Problem

Developers are building skills in prompting AI rather than understanding fundamentals. Simon Willison observes: "LLM tools will always gravitate towards being most useful to senior developers. It is also only devs with solid experience who can quickly evaluate whether a change is safe enough to entrust to an agent."

The tools amplify expertise. They don't create it. A generation of developers who learned through AI assistance may lack the foundation to evaluate what the AI produces.

"I think AI agents are amazing as long as you are the driver & reviewing its work. AI agents become problematic once you're not making them adhere to engineering principles that have been established for decades." — Developer survey respondent
The Strategist — Competitive Dynamics

The Three-Way Race

The coding agent market has consolidated into a three-way competition between very different players with very different strategies.

Anthropic: The Research Lab

Anthropic's strategy: build the best models, let the ecosystem build the tools. Claude Code is deliberately minimal—"low-level and unopinionated, providing close to raw model access." The Claude Agent SDK enables others to build on their infrastructure.

Strengths: Best-in-class coding models (Sonnet 4.5 at 77.2% SWE-bench). Advanced tool use. Model Context Protocol (MCP) becoming industry standard.

Weaknesses: Not an IDE company. Dependent on others for distribution. The "neutral platform" strategy requires partners who might become competitors.

OpenAI: The Platform Play

OpenAI's strategy: vertical integration through ChatGPT. Codex lives inside the world's most popular AI interface. GPT-5.2-Codex delivers state-of-the-art performance.

Strengths: Massive distribution (ChatGPT has 300M+ users). Brand recognition. Capital ($13B from Microsoft). Integrated workflow from conversation to code.

Weaknesses: Enterprise concerns about data privacy. Jack-of-all-trades positioning vs. coding specialists. Microsoft relationship creates strategic constraints.

Cursor: The Vertical Champion

Cursor's strategy: own the developer experience end-to-end. IDE, agent, code review (via Graphite acquisition), enterprise deployment.

Strengths: Best-in-class UX. 100x enterprise growth. Model-agnostic (can use Claude, GPT, etc.). Pure-play focus.

Weaknesses: Dependent on underlying model providers. VS Code fork means Microsoft could clone features. High valuation creates expectations.

The 2026 Outlook

Gartner forecasts that by end of 2026, 40% of enterprise applications will feature task-specific AI agents, up from less than 5% in 2025.

The strategic question: does the value accrue to models (Anthropic, OpenAI), tools (Cursor, Replit), or orchestration (LangChain, Microsoft)?

Historical patterns suggest tools win in the short term, platforms in the long term. But AI moves faster than historical patterns.

Synthesis — What's Actually Happening

The Transformation That's Already Here

Every perspective above contains truth. The capital is flowing. The tools are real. The concerns are valid. The competition is fierce. Holding them together reveals what's actually happening.

The New Division of Labor

Software development is splitting into two activities:

  1. Specification: Describing what the code should do, in natural language or structured prompts
  2. Verification: Reviewing, testing, and validating what the AI produces

The actual writing of code—the thing developers spent 80% of their time doing—is becoming automated. This doesn't eliminate developers; it changes what developers do.

The emerging consensus: developers evolve from "coders" to "conductors." Less time grinding boilerplate, more time orchestrating agents and verifying results.

The Seniority Premium

The tools amplify expertise. A senior developer with deep system understanding can direct agents effectively. A junior developer without that foundation produces code nobody fully understands.

This creates a paradox: the tools that promise to democratize coding may actually widen the gap between senior and junior developers. The 20% decline in junior developer employment may be the leading edge of this dynamic.

The Valuation Reality

$29B for Cursor, $350B for Anthropic, $9B for Replit—these numbers only make sense if coding agents capture a significant portion of the global software development market ($600B+ annually in developer salaries alone).

That capture is plausible. If AI reduces the person-hours needed to ship software by 50%, that's $300B in value created or redistributed. The question is where the value lands: with tool companies, model providers, or enterprises that become more efficient.

What We Actually Know

  • The adoption is real. 85% of developers using AI tools isn't hype; it's survey data from JetBrains and Google.
  • The productivity gains are real. 42% of committed code being AI-generated represents a genuine shift in how software gets written.
  • The quality concerns are real. More code, produced faster, with less human understanding, creates risks that haven't fully materialized.
  • The employment effects are real. 20% decline in junior developer employment correlates with tool adoption, causation unclear.
  • The capital deployment is real. $10B rounds for Anthropic, $2.3B for Cursor—these are concrete commitments, not paper valuations.

What We Don't Know

  • Whether current tools represent the endgame or a transitional phase
  • How the model provider / tool builder value split evolves
  • Whether security and quality concerns limit enterprise adoption
  • What happens to the junior developer pipeline
  • Which specific companies win vs. which category wins

The Only Honest Conclusion

Software development is being transformed. The transformation is happening faster than most predictions suggested. The tools available today are genuinely useful, genuinely limited, and genuinely improving.

The hype is real because the underlying capability is real. The concerns are valid because the transformation is disruptive. The uncertainty is appropriate because we're in the middle of something, not at the end.

Anyone who tells you exactly how this plays out is selling something. The honest position is to watch closely, adapt quickly, and avoid both uncritical enthusiasm and reflexive skepticism.

The coding agent wars aren't about which tool wins. They're about whether "writing code" remains a human activity or becomes an instruction we give to machines. That question is being answered in real time, and the answer is "both, uncomfortably."
